Tracking — Google Setup Guide

Overview

The Tracking page connects the Rally App to Google so that location updates sent by the mobile Tracking PWA can be received, stored and shown on the event map.

The Rally App may already have a Google Apps Script connection created from Admin for entries, controls and results. Tracking requires a second, independent Apps Script project.

Why Tracking uses a separate Apps Script

Tracking receives frequent live location updates and writes them to its own tracking log. Keeping this separate from the Admin connection means:

  • tracking data cannot interfere with entries, controls or results;
  • the tracking log can be opened and managed independently;
  • Tracking can be tested, reset or updated without affecting the proven Rally Admin connection;
  • the Tracking PWA uses its own Web App URL.
Important: Do not replace or reuse the Apps Script URL already saved in Admin. Create a new Apps Script project and use its new Web App URL only in the Tracking card.

Before you start

You need:

  • the Google account already used for the Rally App;
  • access to Google Drive;
  • the Tracking page open on the desktop;
  • the Tracking Code.gs file supplied with the Tracking system.

Key steps

  • Create a new Google Apps Script project.
  • Copy the Tracking Code.gs script from the Tracking card.
  • Paste it into the new Apps Script project.
  • Deploy it as a Web App.
  • Copy the new Web App URL into the Tracking card.
  • Save and test the Tracking connection.

Step 1 — Open Google Drive

  1. Open your web browser.
  2. Go to drive.google.com.
  3. Sign in using the Google account used for the Rally App.

Step 2 — Create a separate Apps Script project

  1. In Google Drive, click New.
  2. Select More.
  3. Choose Google Apps Script.

A new Apps Script project will open.

Give the project a clear name, for example: Rally Tracking.

Step 3 — Prepare the Apps Script editor

When the editor opens, you will normally see:

  • a file named Code.gs in the left panel;
  • sample code in the editor area.

The sample code will be replaced by the Tracking script.

Step 4 — Copy Tracking Code.gs

  1. Return to the desktop Tracking page.
  2. Click the blue Tracking button at the far right.
  3. Under First time setup, click Open Code.gs file.
  4. Click inside the code page.
  5. Press Ctrl+A to select all.
  6. Press Ctrl+C to copy.

You can now close the code page.

Step 5 — Replace the default script

  1. Return to the new Google Apps Script tab.
  2. Click inside the editor.
  3. Press Ctrl+A to select all existing code.
  4. Press Delete.
  5. Press Ctrl+V to paste the Tracking Code.gs script.

Step 6 — Save the script

  1. Click the Save icon, or press Ctrl+S.
  2. Wait until the save message disappears.

Step 7 — Deploy as a Web App

  1. Click Deploy at the top right.
  2. Select New deployment.
  3. Choose Web app.

Use these settings:

  • Execute as: Me
  • Who has access: Anyone or Anyone with the link
  1. Click Deploy.
  2. When prompted, allow the required permissions.

Step 8 — Copy the Tracking Web App URL

After deployment, Google will show a Web App URL.

Copy this address. This is the independent Tracking connection URL.

Step 9 — Connect the Tracking page

  1. Return to the desktop Tracking page.
  2. Open the blue Tracking card.
  3. Under Setup, enter the organiser's mobile number, including the international prefix.
  4. Paste the new Tracking Web App URL into Google connection URL.
  5. Click Save & test.

If successful, the status pill will show Connected.

Tracking data

Use Open tracking log to open the separate Google log used to receive location updates from the Tracking PWA.

This log is independent of the entry and control sheets used by the main Rally App.

Seven-day tracking history

The Tracking log keeps the current tracking day and the previous six tracking days, giving a rolling history of seven tracking days.

  • Each tracking day runs from 03:00 to 02:59 the following morning.
  • Older tracking rows are removed automatically after they fall outside the seven-day history.
  • The heading row is always retained.
  • No manual clearing is required during normal use.

The seven-day history limits the long-term size of the Google sheet. Download or copy any older tracking records before they expire if they are required for a permanent archive.

Tracking link

The Tracking link buttons are used to send the link that opens the Tracking PWA on a mobile device.

  • Copy link copies the Tracking PWA link so it can be pasted elsewhere.
  • Email link prepares an email containing the Tracking PWA link.
  • WhatsApp prepares a WhatsApp message containing the Tracking PWA link.

When the link is opened on the phone, the Tracking PWA loads with the rally, day and route information carried by the link and connects to the independent Tracking Apps Script.

Normal use

  • The organiser opens the desktop Tracking page.
  • The Tracking PWA link is sent to the required mobile device.
  • The user opens the link and runs the Tracking PWA during the event.
  • Location updates are sent to the separate Tracking log.
  • The desktop Tracking page displays the latest entrant positions and status.

If the connection changes

If the Tracking Apps Script is redeployed with a new Web App URL, return to the Tracking card, select Clear, paste the replacement URL and select Save & test again.

Changing the Tracking URL does not alter the Apps Script connection already saved in Admin.
